Trigger and Popup

When enabled, selection uses button trigger mode; when disabled, it uses hotkey-only mode. This stays in sync with Trigger mode and the tray menu.

When disabled, double-click selection no longer shows the Translate button. Drag selection still follows the trigger mode above.

App Appearance and Startup

macOS only. Clicking the Dock icon opens Settings.

When enabled, the app starts at login and stays in the tray. Development mode does not write a system login item.

Speech

Web Page Translation

The app reads the current page text only after you open the built-in reader and explicitly click Extract or Translate. It never reads pages already open in your system browser.

Higher concurrency translates long pages faster but increases momentary load on the provider and may trigger rate limits; use higher values only with a self-hosted or high-quota channel.

When enabled, the reader reads image bytes through the current page session and falls back to a screenshot of the image region when needed. Images that fail recognition, are too small, or exceed the limit are skipped without affecting text translation. Images are processed locally, and OCR results are sent to the selected translation service only while translating the current page.

AI Translation

Use a local or cloud large language model for selection translation. Ollama, OpenAI-compatible, and Claude Code (Anthropic)-compatible HTTP protocols are supported. The API key is stored securely on this device only and is never shown again in the page.

    Microsoft Translator

    Uses Microsoft Bing online translation. No Azure account, subscription key, or region is required. Once enabled, it joins the automatic translation fallback chain.

    This channel relies on temporary parameters from Bing web translation and is not a publicly documented Microsoft developer API with stability guarantees. The interface may break if the service changes; on failure, the app automatically switches to the next channel.

    Not tested

    Translation Channels

    Channels are tried in the following order by default; you can also choose a preferred API at the bottom of the popup. If the preferred API fails or its circuit breaker opens, the app automatically switches to the next one and keeps your preference for future translations.

    1. DingTalk — used first when enabled and fully configured
    2. Microsoft Translator — no subscription required; used before free channels such as DeepLX when enabled
    3. Self-hosted DeepLX — configurable and the most stable (recommended)
    4. Public DeepLX — free, may be rate-limited
    5. Google — free; some networks require a proxy
    6. MyMemory — fallback with no registration but a free quota limit

    Self-hosted DeepLX

    You can configure multiple service URLs, separated by English or Chinese commas. Translations rotate across the URLs and automatically switch on failure.

    Network Proxy

    Supports HTTP, HTTPS, SOCKS4, and SOCKS5, for example socks5://127.0.0.1:7890.

    Separate multiple rules with semicolons; keep <local> and localhost for a local DeepLX service.

    Service Control

    Stopping the service exits the tray icon and selection translation; restart the app when you need it again.

    Selection Diagnostics

    Records the hit level, duration, and failure reason for each selection. Only the last two days are kept, and no selected text is stored.
