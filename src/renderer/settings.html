触发与弹窗

开启后切换为按钮触发；关闭后切换为仅快捷键。与上方“触发方式”以及托盘菜单开关保持同步。

应用外观与启动

仅 macOS 生效；点击 Dock 栏图标会直接进入设置页面。

开启后应用会在登录系统时自动启动并常驻托盘；开发调试模式下不会写入系统登录项。

    微软翻译

    使用微软 Bing 在线翻译，无需配置 Azure 账号、订阅密钥或 Region，启用后即可参与自动翻译降级链路。

    翻译通道

    默认按以下顺序依次尝试；也可在悬浮窗底部选择首选 API。首选 API 失败或熔断后会自动切换下一个，并保留首选设置供后续翻译继续优先使用。

    1. 钉钉翻译 — 启用且配置完整时优先使用
    2. 微软翻译 — 免订阅配置，启用后在 DeepLX 等免费通道前使用
    3. 自建 DeepLX — 可配置，最稳定（推荐）
    4. 公共 DeepLX — 免费，可能限流
    5. Google — 免费，部分网络需配置代理
    6. MyMemory — 免注册兜底，有免费额度限制

    用 Docker 一键部署：把命令里的「你的dl_session值」替换为 DeepL 登录后的 dl_session Cookie，然后在终端执行。

    网络代理

    支持 HTTP、HTTPS、SOCKS4、SOCKS5，例如 socks5://127.0.0.1:7890。

    多个规则使用分号分隔；本机 DeepLX 建议保留 <local> 和 localhost。

    服务控制

    停止后托盘图标和划词翻译功能都会退出，需要使用时请重新启动应用。
