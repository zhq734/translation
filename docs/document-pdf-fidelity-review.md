## 本次已修复

### 1. 颜色归属必须由文字证据确定

旧实现把第 N 次显示操作的颜色赋给第 N 个非空文本项，第一次合并或拆分后就会持续错位。

新实现从绘制字形的 Unicode 构建颜色流，规范化空白和连字后与提取文本核对，再按字符绑定颜色。同一文本项可保留多个颜色片段，几何信息仍属于原文本项，不按字符重新估算宽度。

同页字符流无法完全对应时，保守使用默认文字颜色并给出 `pdf-text-color-unavailable` 告警，不用模糊匹配猜测颜色。页外文字、双向文本、特殊字体等仍可能触发此降级。

### 2. 修复颜色状态和数值单位

- PDF.js RGB 操作符返回字节通道，`1` 应是深色通道，不能再当作归一化的 `1.0` 放大到 `255`。
- Form XObject 与普通图形状态保存/恢复均参与颜色栈，初始填充色使用 PDF 默认黑色。
- 多颜色文本的换行、英文空格、代码缩进同步到颜色分段，避免新样式分段导致内容粘连。

### 3. 可读性优先的重排降级

当前重排模型没有恢复任意矢量底板。对落在重排纸面上的文字，如果与白纸对比度低于 3:1，统一改为深色，并按页给出 `pdf-text-contrast-adjusted` 告警。

这是防止隐形文字的可读性兜底，不是完整 WCAG 合规声明，也不是原色保真。原文侧仍显示原始 PDF；统一模型中的修正供译文预览和 PDF 导出共用。

已有图片底图的覆盖文字和表格叠图内文字不走白纸兜底，避免把正确的“深底白字”改成“深底黑字”。未修改 OCR、DOCX、EPUB 或 HTML 的色彩策略。

## 尚存的设计问题与建议

| 优先级 | 证据或风险 | 推荐设计 |
| --- | --- | --- |
| P1 | 第 4 页彩色按钮、卡片底板、圆角及阴影未进入重排结果 | 明确区分“阅读重排”和“保留版式”。保版模式需要保留装饰背景并在文本区覆写，不应通过把整页图片贴在译文下方造成双重文字 |
| P1 | 第 4 页原始一页，在现有重排导出中变成两页 | 允许续页以避免裁字，但显示源页到输出页映射；预览、导出共享布局约束。不能承诺译后页数不变 |
| P1 | 历史快照持久化完整旧模型，恢复不会自动执行新解析 | 增加解析器版本与显式重新解析入口；保留手改译文，只有源指纹和目标定位可靠时迁移。不得静默清空历史或套用过期几何 |
| P1 | 页 7 有阅读顺序不确定告警；页 1、11 有文本重叠告警 | 对这类页显示可定位的复核提示；复杂多栏/流程图采用区域分组，不把文本的几何顺序等同于语义顺序 |
| P2 | 第 4 页部分 FontAwesome 图标在导出中显示缺字符号 | 明确正文与图标字体的责任：正文使用可嵌入字体，图标保留矢量或局部图片；用字形覆盖率检查，而不只依赖 `encodeText` 是否抛错 |
| P2 | 色彩匹配失败时整页安全回退，无法保证 RTL/特殊字体原色 | 未来用文本矩阵、字体、字形索引辅助定位；保留低置信度告警，不做仅靠近似字符串的无提示匹配 |
| P2 | 页 37 有公式识别不确定告警 | 保留原公式并标记复核；不能把数学符号或特殊图标当普通句子翻译 |

以上为审查结果与后续建议，**不代表保版模式、历史迁移、字体保真或阅读顺序问题已在本次实现**。
