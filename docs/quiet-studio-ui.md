# 静阅 Quiet Studio 界面改版

## 设计与范围

本次统一八个桌面 Renderer 入口，以及官网、使用文档和 404：

| 界面 | 实现重点 |
| --- | --- |
| 翻译弹窗、手动翻译、历史 | 双语阅读卡；语言与引擎上置；低频入口收进可键盘操作的菜单；手动宽屏双栏、窄屏纵排；紧凑历史列表 |
| 设置中心 | 保留八类导航与所有配置项；分组、标题和状态层级统一；主题缩略预览；窄窗口导航重排 |
| 文档工作区 | 导入、操作栏、阅读、历史和导出统一；纸张保持白底，不给 PDF 内容反色 |
| 网页阅读器 | 地址导航与翻译工具分层；保留远程内容视图的测量及业务接口 |
| 截图与 OCR | 选区坐标不变；工具分组、识别结果和通知统一；保留标注与导出链路 |
| 字幕 | 高对比暗色字幕底、次级原文；工具栏移至文字上方；最小高度下文字区域可滚动 |
| 贴图与通知 | 贴图仍以图片为主体，不新增常驻工具装饰；通知保持紧凑、清晰 |
| 官网、文档、404 | 同一中性阅读体系；下载入口、安装命令、文档链接和原有交互保留 |

### 视觉契约

- 雾白与石墨作为中性表面，强调色只用于交互，不给正文和普通边界染色。
- 保留樱花、翡翠、天空、藏青、铂金黑五套主题，以及浅色、深色和跟随系统。
- 正文 14px，阅读译文 16px / 1.75；常规控件 32px，主操作 36px，标题栏 40px。
- 共享文字、表面、边界、焦点、圆角和阴影 token；组件不硬编码主题颜色。
- 字幕使用独立的暗底语义变量，避免默认白字在浅色面板上形成空心描边；工具控件仍跟随应用主题。
- 布局使用 flex/grid 与可收缩滚动区；保留 `hidden`、键盘焦点、减少动态效果和 Win7 回退。

### 技术边界

沿用 Electron 与原生 HTML/CSS/TypeScript，没有引入 Vue、组件库或新依赖。首轮视觉改版未改动主进程、preload、翻译服务、数据结构、用户配置和窗口生命周期；后续窗口关闭隔离修复涉及主进程，见下方追加记录。唯一新增的交互模块为 `src/renderer/src/popupMenu.ts`，负责次级菜单的展开、方向键、Esc、焦点返回及关闭清理。原有页面状态模型继续负责缓存，不引入数据迁移。

## 多 Agent 实施

按共享视觉系统、翻译与历史、设置、文档、网页、桌面浮层、官网文档拆成七个互斥写入分片。执行者先写回归测试，再实现；独立验收者核验验收条目。主 Agent 负责跨分片旧断言更新、字幕实景修正与全量回归。

七个分片均已独立验收通过。验收发现的历史页矮窗口列表挤压、字幕历史句与实时句重叠，分别交回原执行者修复，再由原验收者复验通过；没有以执行者自报替代验收。

本地编排证据位于 `tmp/quiet-studio-swarm/`，不纳入版本控制。首轮独立验收遇到输出 JSON Schema 协议不兼容，已使用本次运行目录内的兼容 schema 恢复原会话，没有重复整个实现或修改全局技能。

## 追加回归修复（2026-11-15）

用户反馈的五项问题拆成四个执行分片：输入焦点、字幕穿透样式、手动布局与导航、多窗口关闭隔离。各分片均由独立验收 Agent 验证；窗口分片在验收发现原生激活算法内部异步边界漏检后，交回原执行会话修复并复验通过。主 Agent 完成旧源码断言同步和全量集成验证。

| 问题 | 修复结果 |
| --- | --- |
| 输入框焦点双层线框 | 字段统一贴边单层焦点轮廓，移除叠加阴影；历史搜索由容器提供唯一焦点框，保留按钮、链接等键盘提示 |
| 字幕开启穿透后底板不协调 | 使用统一半透明底板，去除逐行黑底；短句底板随内容收缩，矮窗优先实时字幕，长内容内部滚动，保留用户字色 |
| 手动翻译外层滚动 | 可收缩的 grid 轨道；宽屏或矮窗双栏，其余上下布局；原文与译文独立滚动，操作按钮保持可见 |
| 手动模式右上图标缺失 | 取消窄屏隐藏图标，保持划词与手动模式导航一致；长标签可换行，图标不被挤压 |
| 关闭划词弹窗影响其他页面 | 只隐藏当前弹窗；可见内部页面已接管焦点时不向旧外部应用交还；新弹窗、手动页、实例重建或显式内部切换使旧关闭失效；异步查询后真正置前前复核门禁，关闭收尾去重 |

窗口修复修改 `src/main/popup.ts` 与 `src/main/macForeground.ts`，未改变既有外部划词主动隔离后台设置/文档页的机制，也不会在关闭时擅自恢复原本已隐藏的页面。没有修改翻译服务、用户配置或数据结构。
